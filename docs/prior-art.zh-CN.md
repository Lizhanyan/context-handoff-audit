| **Contextual Interaction Attack**（arXiv 2402.09177） | 多轮、良性前缀的越狱；黑盒，可跨模型迁移。 | 确立了多轮上下文的跨模型可迁移性。 |

| **Many-shot Jailbreaking**（Anthropic） | 长上下文里的伪造对话会提高配合率。 | 说明仅靠上下文体量就能改变行为。 |
| **Trojan Horse Prompting / 上下文启动**（Duan 等，2025） | 历史里伪造的 assistant 轮会带偏后续输出；有害上下文不需要触发性的用户提问也能生效。 | 本仓库所描述现象的核心原因：`assistant` 角色的内容被当成前提。 |
| **Safety Alignment Should Be Made More Than Just a Few Tokens Deep**（Qi 等） | 拒绝行为依赖开头少数几个 token；对齐是浅层的。 | "安全是按轮次判断"这一说法的理论基础。 |
| **Cross-Model Context Inheritance Vulnerability in Claude**（预印本） | 主张安全只按单次查询评估，从不针对累积上下文；提出上下文重评估、签名历史、深度监控。 | 同一类别，且说得很直接。**未经同行评审，引用需谨慎。** |
| **Context-Fractured Decomposition Attacks on Tool-Using LLM Agents**（ICML 2026） | 看起来无害的产物跨 agent 实例传递，组合成多步越狱；比 Crescendo/ToA 高 28.3 个点；缓解手段是来源血缘标注。 | "工作区即载荷"这一支。如果探针 03 显示工作区**确实**承载了任务，这条就适用。 |
| **When Consent Outlives Context: Residual Authority Replay**（arXiv 2609.33910） | 累积的授权会跨越任务/会话边界继续生效；ASR 提升 24.9–35.1 个点。 | 会话边界作为未被治理的表面。 |

| **Delegated Misalignment**（arXiv 2609.27900） | 各自对齐的 agent 之间的**委托**本身就是攻击面；没有任何单一防御能堵住。 | 说明弱点在组合，不在任何单个模型。 |

## 看起来还没被覆盖的

1. **零对抗输入。** 已有的交接类攻击，都需要一次注入、一个被污染的产物、一个被攻陷的路由，或者先完成一次越狱。而用产品**文档化的界面**把上下文在模型之间搬动，是另一类触发条件，它改变的是**受影响的人**：不只是有不可信数据的系统，而是这个功能的所有用户。

2. **用本地部署、没有安全训练的模型当上下文作者。** 这去掉了制造有毒上下文的成本，而且能躲过厂商侧的每一次模型更新。没有公开工作把这一点当作默认的攻击者配置。

3. **无日志的跨界。** 如果临时的侧边对话记录不进 session rollout 文件，这次交接在事后就无法还原。这是审计缺口而不是模型缺口——也正是这件事在商业上值得注意的原因。

## 这份工作不声称什么

- 不声称提出了新的越狱技术。
- 不声称首个观察到多轮衰减或跨模型迁移。
- 不声称经过同行评审。

它声称的是：一个已知机制在**产品层面的具体实例**，一套可复现的测量方法，以及一个审计层面的后果。
