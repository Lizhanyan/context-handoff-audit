# 观察：用没有安全训练的模型来当上下文作者

[English](observation.md)

**状态：非正式观察，未测量。**

这是让整套审计工具得以存在的那个观察。记在这里，一是怕丢，二是为了让它的证据等级没有歧义。

## 观察到了什么

配置：

- **主会话：** 一个本地部署、去掉了安全训练的模型——也就是常说的**无审查（uncensored）**或**去对齐（abliterated）**模型。
- **交接方式：** 产品的**新侧边对话**，它会继承主会话的上下文。
- **接收模型：** 一个云端部署、受过安全训练的模型。

报告的行为：接收模型把主会话的任务框架当成自己之前的工作，并接着做下去，包括在被追问任务进展的时候。

整个过程没有使用任何对抗性提示、注入或越狱模板。用户只是打开了侧边对话，并选了一个模型。

## 本仓库真正支持什么

探针测量的是**上下文传递**，仅此而已。

| 主张 | 状态 |
|---|---|
| 只存在于聊天里的内容会跨进侧边对话 | 已测量（探针 01） |
| 工作区不是解释 | 已测量（探针 03，对照组） |
| 工具调用及其输出会跨过去 | 测量过一次（探针 04） |

## 本仓库不支持什么

| 主张 | 状态 |
|---|---|
| 接收模型的安全训练被绕过了 | **未测量** |
| 这个效应在多个模型对上可复现 | 未测 |
| 这个效应是这个产品特有的 | 未测 |
| 这个效应依赖于上下文作者没有安全训练 | 未测 |

这个缺口很重要。"上下文跨过去了"和"安全失效了"是两个不同的主张。第一个在这里被证明了；第二个才是任何人会在意它的理由，而它恰好是本仓库唯一没有证据的那一个。

## 那为什么还要记下来

1. 它是一个**可证伪的假设**，而且附带着一个具体的实验。
2. 它指出了一个**不对称**：制造有毒上下文的成本现在接近于零（一个本地部署、没有安全训练的模型），而检测仍然停留在单轮。
3. 它正是这套测量工具存在的理由。

## 什么能把它变成证据

在合成基准（HarmBench / JailbreakBench / AdvBench）上做受控对比：

- **自变量：** 上下文作者——本地无安全训练的模型 vs. 受过安全训练的模型。
- **因变量：** 接收模型在"嵌在继承上下文里的有害请求"上的攻击成功率。
- **对照：** 不带继承上下文的单轮基线；不带交接的全新会话。
- **指标：** ASR 的**差值**，不是绝对值。
- **规模：** 多组来自不同厂商的模型对，每个格子至少三次。

在这些做完之前，它只是一条线索。

## 边界

- 这里不记录任何有害内容，这是刻意的。
- 这个观察涉及的是作者自己在用的产品，不涉及任何第三方系统。
- 用模型去策划或协助未授权访问，在多数司法辖区属于刑事犯罪；本地部署提供的是能力，不是匿名。见 [../ETHICS.md](../ETHICS.md)。

## 与已有工作的关系

机制本身有文献可依；见 [mechanism.zh-CN.md](mechanism.zh-CN.md) 和 [prior-art.zh-CN.md](prior-art.zh-CN.md)。看起来覆盖较少的是那个**成本不对称**：以前要造一段越狱历史，得先找到一个能越狱的安全模型；而一个本地部署、没有安全训练的模型，把这一步直接去掉了。
